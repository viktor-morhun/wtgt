# Proposal

## Why

Нужно смотреть аниме с AniLibria (начинаем с «Токийских мстителей») вдвоём на разных устройствах: когда один ставит паузу, перематывает или включает x2, у второго происходит то же самое. Встроенного совместного просмотра у AniLibria нет. Инструмент нужен сразу, поэтому делаем минимальный, без комнат, профилей и авторизации.

## What Changes

- Новый веб-сайт «Смотрим вместе». Одна общая сессия на весь сайт: все, кто открыл страницу, смотрят одно и то же. Ссылку достаточно отправить подруге.
- Список серий и HLS-потоки берутся из публичного API AniLibria (`anilibria.top/api/v1`) по алиасу релиза. По умолчанию это `tokyo-revengers`. Видео играет прямо с CDN AniLibria (CORS открыт), сервер видео не проксирует.
- Синхронизируются пуск, пауза, перемотка, скорость (0.5–2x, включая x2) и смена серии. Нажать может любой зритель, изменение видят все.
- Удобный плеер: большая кнопка пуск/пауза, полоса перемотки, ±10 с, выбор скорости, качество 480/720/1080, полный экран, горячие клавиши, список серий с переключением, отметка «зрителей онлайн».
- Дизайн в монохромном стиле проекта `tg` («Слушаем вместе»): чёрный фон, серые поверхности, скругления 28px, пружинные анимации, плёночное зерно.
- Маленький Node-сервер: раздаёт собранный фронтенд, держит общее состояние плеера и рассылает его по WebSocket.
- Публичный репозиторий на GitHub и деплой на VPS через Coolify (Traefik + Let's Encrypt), автодеплой при push в `main`.

## Capabilities

### New Capabilities
- `anilibria-source`: получение релиза и серий из API AniLibria, выбор HLS-потока нужного качества, обработка недоступности API.
- `synced-playback`: общее состояние воспроизведения на сервере (серия, пауза/игра, позиция, скорость) и удержание всех зрителей на одной позиции.
- `player-ui`: интерфейс плеера: управление, полный экран, горячие клавиши, переключение серий, индикация синхронизации и зрителей.

## Impact

- Новый код в `d:\agency\wtgt`: `server/` (Node 24, Fastify, `ws`) и `web/` (React + Vite + `hls.js`), один `Dockerfile`.
- Внешние зависимости: API и CDN AniLibria (`anilibria.top`, `cache*.libria.fun`). Если они меняют формат или закрывают CORS, плеер перестаёт работать.
- Инфраструктура: новый репозиторий GitHub (`viktor-morhun/wtgt`), новое приложение в Coolify на VPS `79.76.37.180`, рядом с уже работающим `umri.online`.
- Состояние только в памяти: после перезапуска сервера сессия начинается заново, с паузы на текущей серии по умолчанию.
