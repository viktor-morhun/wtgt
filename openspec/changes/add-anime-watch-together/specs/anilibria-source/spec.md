# Spec Delta

## Purpose

Получение релиза AniLibria и его серий с HLS-потоками, чтобы плеер мог показать список серий и воспроизвести выбранную в нужном качестве.

## ADDED Requirements

### Requirement: Загрузка релиза по алиасу
Система SHALL получать данные релиза (название, постер, список серий с номером, названием, длительностью и HLS-ссылками 480/720/1080) из публичного API AniLibria по алиасу релиза. Если комната ещё не выбирала релиз, используется алиас по умолчанию `tokyo-revengers`.

#### Scenario: Первый запуск
- **WHEN** зритель открывает сайт, а сессия только что создана
- **THEN** показывается релиз «Токийские мстители» и список из всех его серий (24 на момент написания), отсортированных по номеру

#### Scenario: Серия без видео
- **WHEN** у серии в ответе API нет ни одной HLS-ссылки
- **THEN** серия видна в списке как недоступная, и её нельзя выбрать

### Requirement: Смена тайтла ссылкой AniLibria
Система SHALL позволять сменить релиз сессии комнаты: зритель вставляет ссылку на страницу релиза AniLibria (`https://anilibria.tv/release/<alias>.html`, `https://aniliberty.top/anime/releases/release/<alias>` и т.п.) или просто алиас. Смена релиза переключает всех зрителей комнаты на первую серию этого релиза, на паузе.

#### Scenario: Вставлена корректная ссылка
- **WHEN** зритель вставляет `https://anilibria.tv/release/tokyo-revengers.html`
- **THEN** алиас `tokyo-revengers` извлекается, релиз загружается, и у всех зрителей открывается серия 1 на паузе с позиции 0

#### Scenario: Неизвестный алиас
- **WHEN** зритель вставляет ссылку, по которой API отвечает «не найдено»
- **THEN** зритель видит сообщение «Релиз не найден», а комната остаётся на прежнем релизе

### Requirement: Выбор качества потока
Система SHALL по умолчанию воспроизводить качество 720p, если оно есть, иначе ближайшее доступное. Зритель MAY сменить качество (480/720/1080) только у себя. Смена качества не меняет позицию и не затрагивает других зрителей.

#### Scenario: Смена качества во время просмотра
- **WHEN** зритель на 05:00 переключает качество с 720 на 1080
- **THEN** видео продолжается с ~05:00 в 1080p, а у второго зрителя ничего не меняется

### Requirement: Недоступность AniLibria
Система SHALL показывать понятное сообщение и кнопку «Повторить», если API или CDN AniLibria недоступны. Состояние общей сессии при этом не теряется.

#### Scenario: API не отвечает
- **WHEN** запрос к API AniLibria завершается ошибкой или не укладывается в 10 с
- **THEN** вместо плеера отображается «AniLibria не отвечает» с кнопкой «Повторить», а остальные зрители продолжают смотреть
