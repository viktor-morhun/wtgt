# Смотрим вместе

Сайт для совместного просмотра аниме с AniLibria: зашёл, ввёл ник, создал комнату, отправил ссылку другу — он вводит свой ник, и у вас одно и то же видео. Пуск, пауза, перемотка, скорость (0.5–2x) и смена серии — у всех в комнате сразу, кто бы ни нажал. Аккаунтов и общего списка комнат нет.

Адрес: **https://watch.umri.online**

- Комната — `/r/<код>`; «Пригласить» копирует ссылку (на телефоне — «Поделиться»). В шапке — кто в комнате; клик по аватаркам — сменить ник. Подсказки поверх видео говорят, кто что нажал: «Вика: пауза».
- По умолчанию в комнате «Токийские мстители»; «Сменить тайтл» — вставить ссылку на любой релиз AniLibria (`https://anilibria.tv/release/<алиас>.html`) или алиас.
- Чат комнаты: на телефоне — под видео, поле ввода над клавиатурой, видео остаётся на экране; на ПК — вкладка в правой колонке. Последние 100 сообщений комната помнит, в полноэкранном режиме чужие сообщения всплывают поверх видео.
- Серия закончилась — у всех включается следующая.
- Недавние комнаты — на главной: тайтл, серия и время, на котором остановились (хранятся в браузере, без аккаунта). Клик — сразу в комнату под сохранённым ником; ✕ — убрать из списка.
- Качество (480/720/1080) и громкость у каждого свои.
- Клавиши: пробел/K — пауза, ← → — 10 с, Shift + < > — скорость, F — полный экран (или двойной клик), M — звук, N / P — серии.

Спецификации и решения: [openspec/changes/add-anime-watch-together](openspec/changes/add-anime-watch-together/).

## Как устроено

```
server/  Fastify: статика web/dist (+ SPA fallback), GET /healthz, GET /api/release/:alias,
         POST /api/rooms, WebSocket /ws?room=<код>
web/     React + Vite + hls.js; стиль — из listen-together (монохром, тёмная тема)
shared/  протокол WebSocket (zod), расчёт позиции и сверка часов, разбор ссылок AniLibria
```

- **Видео** играет напрямую с CDN AniLibria (HLS, CORS открыт); сервер видео не трогает. Список серий и ссылки на потоки сервер берёт из `https://anilibria.top/api/v1/anime/releases/<алиас>` и кэширует на 10 минут.
- **Синхронизация.** Источник правды — сервер: серия, пауза/игра, позиция на момент последнего изменения (`anchor` по часам сервера), скорость, `version`. Клиент сверяет часы с сервером (медиана ping/pong) и раз в 500 мс считает ожидаемую позицию `position + (сейчас − anchor) × rate`. Расхождение больше 1 с (на паузе — 0,3 с) — перемотка. Кто отстал из-за загрузки — догоняет, остальные не ждут.
- Команды уходят только от кнопок и клавиш, события `<video>` на сервер не отправляются — поэтому нет эха. Исключение — нативный полный экран на iPhone.
- **Комнаты** живут в памяти: у каждой своя сессия. Неизвестный код создаёт комнату заново, поэтому ссылки переживают перезапуск. Если все ушли во время просмотра — пауза; пустая комната удаляется через 30 минут.
- **Продолжение просмотра.** Клиент запоминает в `localStorage` (`wtgt.rooms`, последние 20) комнату, тайтл, серию, время и скорость — при каждом изменении и раз в 5 с во время игры. При каждом подключении к комнате он шлёт `restore {alias, episodeId, position, rate}` (после обрыва связи — с места, где была сессия). Сервер применяет его на паузе, только если в комнате ещё никто ничего не менял, — то есть после перезапуска сервера или удаления пустой комнаты она продолжается с того же места, а живую сессию `restore` не трогает.
- **Ник** хранится в браузере; клиент шлёт `hello {name}` после «Присоединиться», и в списке участников видны только представившиеся. Писать в чат (`chat {text}`) тоже могут только они.

## Разработка

Нужны Node 24+ и pnpm 10.

```bash
pnpm install
pnpm dev          # сервер на :3000 + vite на :5173 (проксирует /ws и /api)
```

Открыть http://localhost:5173, создать комнату и открыть её ссылку во второй вкладке.

Проверки:

```bash
pnpm lint && pnpm format:check && pnpm typecheck && pnpm test && pnpm build
```

Прод локально: `pnpm build && pnpm start` → http://localhost:3000.

Переменные окружения (все необязательные, см. `.env.example`): `PORT` (3000), `DEFAULT_RELEASE` (`tokyo-revengers`), `WEB_DIST`, `LOG_LEVEL`.

## Деплой в Coolify

Приложение — один контейнер из `Dockerfile`, без volume и секретов. Развёрнуто так:

- Coolify → проект **wtgt** → environment `production` → приложение **wtgt** из публичного репозитория `https://github.com/viktor-morhun/wtgt`, ветка `main`.
- Build Pack: Dockerfile, порт `3000`, health check `/healthz`.
- Домен `https://watch.umri.online` (A-запись на VPS) — сертификат выпускает Traefik (Let's Encrypt).
- Автодеплой: webhook GitHub (push) → `http://79.76.37.180:8000/webhooks/source/github/events/manual` с секретом из настроек приложения (Webhooks → GitHub). Push в `main` — новый деплой.

WebSocket идёт через тот же домен (`/ws`), отдельных настроек Traefik не нужно. При редеплое комнаты начинаются заново (ссылки продолжают работать). Проверка: `curl https://watch.umri.online/healthz` → `{"ok":true}`.
